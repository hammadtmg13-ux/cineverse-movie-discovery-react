# CineVerse - Movie Discovery App

A movie discovery app built with React 18. Search movies, filter by genre, see ratings, and build your own watchlist.

## Features

- Browse 8 movies with genre, year, rating and duration
- Live search by movie title
- Filter by genre: Sci-Fi, Drama, Thriller, Adventure, Action, Romance, Comedy
- Add or remove movies from your watchlist, with a live count
- Click any movie to open a detail view with its full description
- Fresh cinematic style: deep violet gradients, glass cards and pink accents

## Tech Stack

- React 18 with hooks (useState, useMemo)
- Plain CSS, no extra UI library
- Create React App structure

## Setup

1. Run `npm install` to install dependencies.
2. Run `npm start` to run the app in development mode.
3. Open http://localhost:3000 in your browser.

## Files

- `src/App.jsx` - The whole app: movie data, search, genre filters, watchlist and detail modal
- `src/index.js` - React entry point
- `src/index.css` - The new cinematic style
- `public/index.html` - HTML shell
- `package.json` - Dependencies and scripts
